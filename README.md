# Shopping List Management System

A simple C++ program to manage a shopping list.

## Features
- Add items
- Remove items
- Search for items
- Display all items
- Exit the program

## Sample Output

```text
--- Shopping List Menu ---
1. Add Item
2. Remove Item
3. Search Item
4. Display All Items
5. Exit

Shopping List:
1. Milk
2. Bread
3. Eggs

Exiting program.
```

## How to Run

```bash
g++ ShoppingList.cpp -o ShoppingList
./ShoppingList
```
